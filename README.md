# Omid Reyhanigalangashi — GitHub Pages portfolio

This revision preserves the original navy/teal website design and adds a portrait, academic education section, institutional emblems, professional experience, and scholarly links.

## Deploy
Upload **all files and the images folder** to the root of your GitHub Pages repository. Under Settings → Pages, select Deploy from a branch, main, /(root).

## Before publishing
- Replace the generic GitHub link in `index.html` with your actual GitHub profile.
- Verify the exact 2024 IGARSS publication title and full citation; the site retains the original placeholder warning.
- Confirm the public email address and job title.
- The university emblems and personal photograph are the files you provided.

Open `index.html` locally to preview. No build tools are needed.
